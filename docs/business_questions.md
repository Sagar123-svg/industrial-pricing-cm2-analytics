# Business Questions Answered by This Project

1. Which materials generate the highest revenue?
2. Which materials have negative CM2?
3. Which materials have the lowest CM2 percentage?
4. Which customers receive the highest discounts?
5. Which customers generate the highest/lowest profitability?
6. Which material categories have the highest margin?
7. How has selling price changed over time?
8. How has standard cost changed over time?
9. Which materials experienced significant cost increases?
10. How does discount percentage affect CM2?
11. Which materials require price revision?
12. Which sales organizations have the best profitability?
13. What percentage of transactions are below the target CM2?
14. Which materials have high revenue but poor profitability?
15. Where are the biggest pricing improvement opportunities?

Each question is answered by one or more SQL queries in `/sql/` and/or
visualized in `/charts/`. See the README for a mapping of key findings to
specific files.
